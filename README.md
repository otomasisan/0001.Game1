# ひつじのおるすばん (Little Lamb Waits)

絵本のようにかわいい家で、子ひつじのモコが家族の帰りを待ちながら謎を解く、
2D ポイント&クリックの物語ミステリー。Steam での発売(2028年2月目標)に向けて制作中。

いまは **プロトタイプ** です。第1章「おるすばんの朝」(謎1〜3)と第2章「ながい夕方」(謎4〜7)を
最初から最後まで遊べます。第2章のあとは「第3章は制作中」でタイトルに戻ります。

## 遊び方

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)(標準版、.NET 版ではない)を入れる
2. Godot で `project.godot` を開き、F5(▶)で実行
3. 操作はマウスだけ。場所をクリックで「しらべる」、持ち物を選んでから場所をクリックで「つかう」
4. 詰まったら右上の「ポッポに きく」。押すたびにヒントが具体的になる(3段階)
5. 第2章だけ確かめたいときは、タイトルの「第2章から(テスト用)」を押す。
   このボタンはエディタやデバッグ書き出しのときだけ出て、製品版(リリース書き出し)には出ない

ゲームパッド/Steam Deck 対応、本番の絵・音は今後。

## 第1章でできること

| # | 場所 | 謎 | 答え | 答えが示すこと |
|---|------|----|------|----------------|
| 1 | だいどころ | 母のメモの通りに朝ごはんのお皿を並べる | 窓側から 父・ラム・モコ・(あき)・母 | 家族以外の「誰か」の席がある |
| 2 | いま | ハト時計の針を帰宅時刻に合わせる | 6:40 | 時計はもう動いていない |
| 3 | こどもべや | 絵本を表紙の絵(朝・昼・夕・夜)の順に並べる | 背表紙が「まってて」(英: WAIT) | 待つよう言い聞かされていた |

流れ: メモを読む → 食器棚でお皿 → テーブル(謎1)→ ねじまき → 居間のハト時計に使う → 謎2 →
小さな鍵 → 子ども部屋 → 本だな(謎3)→ 第1章おしまい。

## 第2章でできること

第1章を解き終えると、夕方の色になった家でそのまま第2章が始まる。

| # | 場所 | 謎 | 答え | 答えが示すこと |
|---|------|----|------|----------------|
| 4 | いま | ソファに現れた小箱のダイヤル | カレンダーの赤丸 3・17・24 | 家族は別々の日に出かけた |
| 5 | ラムのへや | 机の引き出しのダイヤル(ラム・モコ) | 背比べの柱の最後の印 4・5 | 兄は4歳のまま、モコはもう追い越した |
| 6 | こどもべや | くもった窓の文字を星の数の順に並べる | 「おそとは えだよ」(英: PAINTED) | 窓の外の景色は絵 |
| 7 | いま | ラジオに引き出しのつまみを付けて周波数を合わせる | 85.5 MHz | 畜産市況の放送「こひつじ 12とう」 |

流れ: 小箱(謎4)→ 兄の部屋の鍵 → 柱を見る → 引き出し(謎5)→ つまみ・ビー玉 →
ラジオ(謎7)。窓(謎6)はいつでも解ける。謎6と謎7の両方を解くと第2章おしまい。

会話中は部屋にいるモコをそっと消す(会話ウィンドウと重ならないように)。話し手の顔は
会話ウィンドウの右上に出る。

## フォルダ構成

```
project.godot
scenes/
  title.tscn, main.tscn
  rooms/      1部屋 = 1シーン(kitchen / living_room / kids_room / brother_room)
  puzzles/    謎ごとの画面
scripts/
  game_state.gd   進行フラグ・持ち物・セーブ/ロード・言語(autoload: GameState)
  story.gd        ★ 謎の流れのデータ。どこをクリックしたら何が起きるか、ヒント文
  main.gd         ルールの実行、部屋移動、謎の表示、ヒント、章の終わり
  room.gd / hotspot.gd / moko.gd   部屋・クリック場所・モコ(仮素材の描画)
  puzzles/        謎の部品(お皿・時計・本・ダイヤル錠・窓の文字・ラジオ)
  ui/             会話ウィンドウ・持ち物欄
i18n/text.csv     日英の全テキスト(tools/text_source.py から生成)
tests/            第1章と第2章を自動で通しプレイするテスト
tools/            部屋シーンとテキスト CSV の生成スクリプト
```

## 仕組みのポイント

- **謎はデータで定義**: `scripts/story.gd` の `RULES` に「条件 → アクション」を書くだけで、
  クリック時の反応・持ち物の受け渡し・部屋移動・謎の起動を組める。コードを触らずに謎を入れ替えられる。
- **章ごとの見た目切替**: `Room.wall_colors` が章(1〜4)ごとの色を持ち、`Hotspot.visible_if`
  (例: `chapter>=2`)で小物を出し分ける。本番は背景画像を「通常・異変・真実」の3枚に差し替える予定。
- **テキストは CSV で日英同時管理**: `i18n/text.csv` を起動時に読み込む(エディタでのインポート不要)。
  `|` はページ送り、`{item}` は差し込み。テキストを直すときは `tools/text_source.py` を編集して
  `python3 tools/text_source.py` を実行。
- **オートセーブ**: 部屋を移動するたび、謎を解くたびに `user://save.json` へ保存。

## テスト

```
godot --headless --path . --import
godot --headless --path . res://tests/smoke_test.tscn
```

第1章と第2章を最初から最後まで自動で遊び、テキストの日英の抜けも確認する。GitHub Actions でも PR ごとに実行。
画面つきで `-- --shots=<フォルダ>` を付けると要所のスクリーンショットを保存する。

## 書き出し(Steam 用ビルド)時の注意

- 書き出し設定の「リソース以外のファイル」に `i18n/*.csv` を追加する(テキストを実行時に読むため)
- 日本語フォントは今は OS のフォントに任せている。発売版では OFL ライセンスの丸ゴシック
  (例: Zen Maru Gothic)を同梱してテーマに設定する
- 絵・音のファイルは Git LFS で管理する(`.gitattributes` 設定済み。初回だけ `git lfs install`)
